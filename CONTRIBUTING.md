# Contributing

Bug reports and pull requests are welcome. Standard GitHub flow: fork, branch, PR against `main`. CI (tests, lint, secret scanning) must pass before merge.

Before contributing code, note the project's licence (`LICENSE`): DoorLockCheck is source-available under the PolyForm Noncommercial License 1.0.0, not a permissive open-source licence. By submitting a pull request, you agree your contribution is licensed under those same terms.

## Code of Conduct

There isn't one. Be a reasonable adult, communicate like one, and disagree about code without making it personal. If that's not something you can manage, this project isn't for you.
